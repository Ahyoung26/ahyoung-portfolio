# About

이 포트폴리오는:

* Interactive AI
* Conversational UX
* AI Workflow
* Admin / Operational Design
* LLM / RAG Planning

기반의 AX 기획 사례를 정리한 AI 서비스 기획자의 프로젝트입니다.

웹 기반 포트폴리오이면서 동시에
PDF 포트폴리오로 export 가능한 구조를 목표로 설계합니다.

# Diagram Principles

This portfolio is diagram-first.

Preferred:

* AI Workflow
* Conversation Flow
* Admin IA
* State Policy
* Operational Structure

Avoid:

* excessive screenshots
* decorative mockups

---

# PDF Strategy

IMPORTANT:
This site must also work as a printable portfolio PDF.

Therefore:

* stable vertical layouts
* minimal interactions
* readable typography
* section-based structure

Avoid:

* sticky sections
* horizontal scroll
* complex motion
