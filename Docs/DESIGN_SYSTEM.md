# Reference Slide Layout

첨부 이미지 기준의 기본 장표 구조:

```txt
Top Nav

Left Content (35~40%) + Right Visual (60~65%)

Insight Bar (Full Width)

Bottom Pagination
```

Left Content 구성:

* Page Label
* Title
* Description
* Key Point 3개

Right Visual 구성:

* 실제 산출물 또는 Placeholder 1개
* Visual 영역 전체 사용
* 내부 카드 반복 금지

Insight Bar:

* 장표의 결론
* 하단 Full Width
* 1~2줄

Bottom Pagination:

* 이전/다음 장표 안내
* 작은 보조 정보로 처리

# Component Rules
