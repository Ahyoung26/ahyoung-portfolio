## Hero Title

Interactive Avatar 서비스 구축

## Description

Avatar 생성부터 실시간 대화까지, 대화형 AI를 실제 서비스로 구현하기 위한 구조 설계

- Avatar 제작에 많은 시간과 비용이 소요됨
- 텍스트 기반 Chatbot 경험만으로는 차별화에 한계 존재

- 품질을 측정 가능한 기준으로 표준화

### My Role

- 서비스 구조 설계
- 대화 경험 설계
- 운영 체계 및 품질 기준 정의

### Insight

사용자는 AI의 답변보다 대화가 자연스럽게 이어지는 경험을 더 중요하게 평가했음.

서비스 관점의 AI 기획

## Description

기술을 사용자 가치로 연결하는 과정에서 얻은 인사이트 정리

### 배운 점

- 사용자 경험은 서비스 흐름에서 완성됨
- 문제 정의가 솔루션 방향을 결정함
- 운영까지 고려한 설계가 중요함

### 어려웠던 점

- AI 품질 측정 기준 부재
- 조직 간 관점 차이 존재
- 기술과 비즈니스 간 균형 필요

### 다음 단계

- 데이터 기반 평가 체계 고도화
- 품질 측정 자동화
- 운영 효율성 강화

### Insight

AI 기술은 빠르게 평준화되지만 사용자 경험과 운영 구조는 쉽게 복제되지 않음.

결국 AI 서비스의 경쟁력은 **사용자 경험을 설계하는 방식**에서 결정됨.
